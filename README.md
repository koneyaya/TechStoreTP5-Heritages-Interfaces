# TechStoreTP5-Heritages-Interfaces
Projet Java du TP5 (TechStore) réalisé dans le cadre de la programmation orientée objet. Il implémente les concepts d’héritage, de classes abstraites, d’interfaces, d’énumérations et la gestion de hiérarchies de classes pour la modélisation de personnes et d’appareils.
